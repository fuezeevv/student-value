# Восстановление целостности продукта — 17.11.2026

## Выбор архитектуры

Сохраняем PostgreSQL, существующий Next backend и нативный React Native клиент. Prisma — слой работы с БД, а прикладные проверки доступа, provenance, XP, Calendar и приглашений уже реализованы проектом. Перенос на Go/Fiber сейчас потребовал бы повторно перенести и проверить эти гарантии и не исправил бы исчезнувшие функции сам по себе. Приоритет — исправление текущих контрактов и паритет возможностей.

Перед изменением доменного кода создана закрытая локальная pg_dump-копия polytech_study вне Git. Рабочая БД не изменялась; артефакты прежних тестов не удалены. Предыдущий checkpoint: 5006140, ветка codex/mobile-safety-review-2026-11-17.

## Реализовано

- Общая транзакция прогресса и operation receipt: ошибка журнала откатывает изменение статуса и XP. Повторы UUID сверяют владельца и hash payload, проверяют текущую аудиторию и возвращают актуальный результат, а не старый снимок.
- Новая очередь использует server version и predecessor receipt. Два действия офлайн не сравниваются с часами телефона; независимое изменение вызывает явный конфликт. Ошибочные черновики сохраняются до обновления/нового выбора пользователя.
- Локальная запись optimistic progress и outbox теперь атомарна. Порядок очереди — порядок вставки, без зависимости от часов устройства. Работа с ошибкой не переотправляется бесконечно как успешная.
- StudentNotes не копируются в новый AuditLog. Все существующие доменные проверки самостоятельной отметки/независимого принятия и компенсации XP сохранены.
- Task API учитывает выбранную группу: другая группа не подменяется собственной. Невалидный bearer возвращает 401. Гостям — только публичная проекция, без файловых дескрипторов, прогресса и неподтверждённых дат.
- SQLite migration 6: cache разделён по guest/user + group. Старый бесконтекстный кэш не читается и не удаляется по префиксам имён. Выход чистит текущий пользовательский кэш.
- Два UI-выхода используют общий logout, удаление SecureStore, приватных материалов и уведомлений. Remote revocation ограничен временем и остаётся best effort при отсутствии сети. Асинхронные ответы проверяют поколение сессии; bearer/user storage разделён по API origin. Смена сервера завершает текущую сессию.
- Прямой RUZ-путь проверяет исходный JSON: сущность, неделю, даты, адресатов каждой пары и интервалы времени. Отсутствующее days не превращается в пустую FRESH неделю. Идентификаторы пар стабильны при перестановке ответа. Native XHR ограничивает время полного ответа и размер передачи.
- Поиск игнорирует ответы старых запросов и показывает ошибку вместо ложного «не найдено». Неподтверждённый статический список преподавателей заменён реальным поиском. Каталог восьми публичных групп общий для web/native. При 404 мобильного timetable API фиксированные публичные группы используют официальный RUZ напрямую.
- Предметы с опубликованной работой остаются в каталоге, даже если на выбранной неделе нет пары. Сбой загрузки заданий не описывается как отсутствие домашней работы. Устаревший ответ другого аккаунта/группы не должен подменять текущий экран.
- Через профиль доступны явно обозначенные веб-разделы, включая панель старосты, настройки оформления, приглашения, Calendar, предложения, достижения, обмен и платформенный обзор по соответствующим правам. Вход в браузере отдельный, права по-прежнему проверяет сервер.
- Сохранённый материал открывает локальное состояние без ожидания сетевого metadata. Для бинарных документов добавлен Android VIEW intent через Content URI с временным read grant; нужен установленный просмотрщик. Проверяется владелец файла, metadata, размер чанков, SHA-256; temp-файлы очищаются при сбое. Хеширование пока читает файл целиком, не является constant-memory streaming.
- Карта ведёт к официальной странице СПбПУ и PDF, без выдуманных координат, этажей и лифтов: https://www.spbstu.ru/campus-map/ . Это внешняя карта с интернетом, не нативный офлайн-навигатор.

## Ограничения приёмки

Проверки на итоговом коде: 40 наборов / 269 unit/integration tests, отдельная локальная studentvalue_test_recovery_final_20261117; root и mobile TypeScript; root ESLint; 24 изолированных web E2E (рабочая БД не изменилась); production build; проверка 67 function traces на отсутствие secrets/fixtures/dev tools; production runtime отказал отсутствующим/поддельным сессиям и dev cookies даже при ALLOW_DEV_AUTH=true. Проверка отката receipt выполнена реальной ошибкой INSERT в тестовой PostgreSQL, без production test-auth hook.

Автотесты и Gradle-сборка не заменяют физическую проверку. В этой работе не вводились реальные Google credentials, не создавались production test users/sessions и не менялись личные учебные результаты. Реальный Google login на Android, cold start, просмотр PDF/DOCX без сети, logout во время скачивания и напоминания Android должны проверяться на телефоне. Полной гарантии отсутствия вылетов нет. Скриншоты прежней версии не считаются доказательством новой.

Не маркировать приложение полностью готовым и не заменять публичный APK до приёмки. Нативная тема, полноценная панель старосты, наложение расписаний и индивидуальный учебный минимум остаются самостоятельными задачами. Не удалять синтетические записи рабочей БД без отдельного digest-bound, аудируемого исправления.
