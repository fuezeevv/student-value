## 1. Дизайн-философия: «Semester as Progression System»

Интерфейс спроектирован для студентов инженерно-технического направления (09.03.01 ИВТ). Это люди, ежедневно работающие с кодом, терминалом, средами разработки и технической документацией.

### Ключевые принципы:
1. **Zero Fluff / High Information Density:**  
   Никаких пустых декоративных баннеров, отвлекающих векторных иллюстраций или детских мультяшных маскотов. Интерфейс строгий, четкий, высококонтрастный и информационно плотный.
2. **Progression as Engineering Dashboard:**  
   Игровая механика семестра строится вокруг понятия **«Закрытие семестра как завершение сложного инженерного проекта / миссии»**:
   - Дискретные вехи (Milestones);
   - Индикаторы допуска к сессии (Requirements Checklists);
   - Четкие статусы готовности и верификации;
   - Время до дедлайна с точностью до минут для горящих задач.
3. **Desktop-First, Fully Responsive:**  
   Основной рабочий инструмент студента — ноутбук (13–16 дюймов), поэтому верстка оптимизирована под горизонтальное использование экрана с сайдбаром или верхним командным меню. На смартфонах интерфейс перестраивается в компактный вертикальный стек.
4. **Accessible Semantics & Contrast:**  
   Поддержка Dark / Light темы на уровне CSS-токенов. Статусы кодируются тройным сигналом: **текст + пиктограмма + цвет** (никогда не полагаемся только на цвет).

### Экран 1: Главная страница (Dashboard — «Что мне делать прямо сейчас?»)

#### Иерархия страницы:
1. **Верхняя панель:** Название группы (`СПбПУ 5130901/40102`), переключатель семестра (`5 семестр, Осень 2026`), глобальный поиск (`Cmd+K`), профиль (Никнейм, Аватар, переключатель темы).
2. **Focus Zone (Primary Action Card):** Главный блок ответа на вопрос *«Что делать прямо сейчас?»*. 1–2 самые критические задачи (наиболее близкий жесткий дедлайн или возвращенные на доработку работы).
3. **Semester Progression Tracker:** Горизонтальный трекер прогресса семестра:
   - Неделя семестра (например, *Неделя 7 из 18*);
   - Суммарный прогресс закрытия обязательных работ;
   - Статус готовности к допускам по ключевым курсам.
4. **Двухколоночный рабочий лэйаут:**
   - **Левая колонка (65%):**
     - Срочные и просроченные дедлайны (Overdue / Today / Tomorrow / Urgent);
     - Задачи в активной работе студента (`IN_PROGRESS`, `READY`, `NEEDS_FIX`);
   - **Правая колонка (35%):**
     - Лента оперативных объявлений старосты и преподавателей (с метками важности и источника);
     - Быстрые ссылки на общие диски группы и методички.

### Экран 3: Страница задания (Task Page)

#### Иерархия страницы:
1. **Хлебные крошки:** `Главная / Курсы / ОТУ / ЛР1: Изучение свойств ОУ...`.
2. **Заголовок и метаданные задачи:**
   - Бейдж типа: `[ЛАБОРАТОРНАЯ РАБОТА #1]`;
   - Статус публикации: `[PUBLISHED]`;
   - Аудитория задачи: `[Вся группа 40102]`;
   - Заголовок задачи;
   - Блок Provenance / Источник происхождения с ссылкой на первоисточник.
3. **Двухколоночный лэйаут выполнения:**
   - **Левая колонка (Контент задания — 65%):**
     - **Индивидуальный вариант студента:** персональные параметры (для студента показывается его вариант из `TaskVariant`, например: *«Вариант 4: Матрица A=[...], передаточная функция W(s)=...»*);
     - **Описание и требования к выполнению:** текст задания, специфика оформления отчета, требования к графикам и анализу;
     - **Связанные материалы:** ссылки на методичку, скрипты инициализации, шаблоны отчетов;
     - **Зависимости:** блокирующие предшествующие задачи (если есть).
   - **Правая колонка (Трекер сдачи студента — 35%):**
     - **Дедлайны:** Блок сроков с датой, типом (`HARD` / `SOFT`), индикатором времени и статусом синхронизации с Google Calendar.
     - **Интерактивный статус выполнения студента:**
       - Выпадающий список персонального статуса: `NOT_STARTED` $\to$ `IN_PROGRESS` $\to$ `READY` $\to$ `SUBMITTED`.
       - Блок подтверждения преподавателем (`Trust Verification`):
         - Если подтверждено старостой/преподавателем: зеленый бейдж `[VERIFIED ACCEPTED]`, дата зачета, кем подтверждено;
         - Если не подтверждено: желтый бейдж `[SELF-REPORTED] (Ожидает проверки преподавателем)`.
     - **Личные приватные заметки студента:**
       - Текстовое поле для ссылок на личный черновик, заметки к защите, вопросы преподавателю.
