# Журнал занятий и восстановление источников

Страница предмета открывается журналом: дата, вид пары, подгруппа или траектория, тема и доступность содержания. Работы и библиотека находятся в отдельных вкладках. Из связанной работы можно перейти к объясняющим её занятиям. Связь по теме не утверждает дату выдачи работы.

Первый срез охватывает расписание группы 5130901/40102 с 01.09 по 02.11.2026 включительно: 144 пары объединены в 130 записей. Две соседние лабораторные пары объединены только при совпадении предмета, дня, вида и адресата; разные подгруппы не объединяются. НИР и военная подготовка представлены по официальному расписанию. Участие в военной подготовке и траектории графики не назначаются автоматически студенту.

В плане 53 исходных текста, 104 материала и ссылки (около 22 МиБ оригиналов и подготовленных копий), пять учебных памяток: четыре по архитектуре и одна по РР1 статистики. У 58 записей пока есть только расписание, у 26 — материалы, у 41 — транскрипция с обзором, у пяти — памятка. Исходные аудио/видео не транскрибировались заново. Фотографии тетрадей ещё не предоставлены. Не утверждать, что весь локальный корпус полностью прочитан или все занятия восстановлены.

Распределение по датам использует конкретную неделю официального расписания и имена датированных записей. Номер презентации или дата ZIP не подменяют дату пары. Подбор презентации по теме маркируется RELATED; предположительная связь — INFERRED. Альтернативная запись New Recording 5 датирована 7 октября по прямому ответу старосты; значительное пересечение с уже найденной записью не создаёт второй лекции. Другие недатированные записи хранятся отдельно. Личные фрагменты транскрипций скрываются; исходные файлы не изменяются.

Синтез содержит прямые ссылки на текущие девять заданий и лекции DL. Домашняя подготовка, показ и загрузка различаются. Необязательные части не становятся обязательными. Текстовые даты и время в интерфейсе DL сохранены раздельно: часовой пояс и расхождения не разрешаются догадкой. Публикация контекста не создаёт новые Task, Deadline, варианты, прогресс или принятие работы.

`LessonContext` хранит степень наполнения, памятку, условия дальнейшей работы, происхождение и digest ручного импорта. Памятка скачивается текстовым файлом и явно отделена от оригинала преподавателя. Части одной записи объединяются; история версий текста предназначена для реальных правок, не для последовательных частей лекции. Обычный редактор позволяет заполнить запись из расписания, сохранив происхождение.

`MaterialFile` содержит проверяемую копию отдельно от обычных запросов материалов. Файлы не лежат в public, Git или function bundle. Страница и API требуют действительного входа и доступа к активному предмету своей группы. Платформенное владение не обходит группу. Файл, связанный только с черновиком занятия, не выдаётся. API возвращает куски не более 1 МиБ; браузер проверяет размер и SHA-256 перед сохранением. Максимум файла — 20 МиБ; крупные исходные дистрибутивы не загружены. Для двух небольших архивов архитектуры сохранены точные исходные ZIP; для остальных доступен исходный документ задания.

Операционные функции не открыты по HTTP. Публикация требует действительного владельца с активной Enrollment, активного предмета своей группы и точного digest. Она идемпотентна и отказывает при изменённой записи, конфликте времени, чужом материале или недоступной связанной работе. Публичное расписание не даёт права менять чужую группу. Каждый импорт записан в аудит; поток из 130 уведомлений не рассылается.

Частный manifest и оперативные инструменты находятся локально, отдельно от Git и deployment upload. Перед production-операциями сохраняются аутентифицированные зашифрованные PostgreSQL snapshots; воспроизводимая схема лежит в миграции 20261102020000_lesson_context_files. Локальная рабочая БД не используется для тестов или наполнения. Автоматического обновления будущего расписания и непрерывного AI-ingestion этот срез не вводит.
